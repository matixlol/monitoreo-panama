## Docling server

Convex node actions can optionally call a Docling Serve instance to post-process PDF extraction (see "Docling Override" in the admin UI).

Configure:

- `DOCLING_SERVE_URL` (example: `https://<your-railway-service>.up.railway.app`)

Railway deployment scaffolding for Docling Serve lives in:

- `services/docling-serve/`
